Trading Assistant / MT5 AI Bridge

A MetaTrader 5 bridge with trading strategies, risk-based position sizing, account-level session guards, SQLite decision journaling, and a monitoring dashboard.

PythonMetaTrader 5SQLiteRisk controls
Source repository ↗

Purpose and outcome

Connects strategy decisions, position planning, risk gates, and a reviewable journal in one trading workflow.

System architecture

Python strategy, planning, sizing, exposure, and session-guard modules sit between market observations and the MetaTrader 5 client. Decisions are recorded in SQLite and rendered through the dashboard module.

Implemented capabilities

  • Intraday and swing strategy engines
  • ATR-based stops and fixed-fractional position sizing
  • Exposure caps and persistent session risk guards
  • Decision journal and dashboard for positions, equity, and engine activity

Typical workflow

  1. Read market data and evaluate the configured strategy.
  2. Plan direction, stops, and position size.
  3. Check account risk, correlated exposure, and session limits.
  4. Journal the decision and review the monitoring dashboard.

Evidence and validation

The repository dashboard generator rendered an empty SQLite demonstration journal and its output was captured in a browser. No live entrypoint or broker adapter was started; no order execution or strategy performance was validated.

Limitations and operating context

Live MetaTrader 5 integration requires Windows and a configured terminal. Automated mode can place orders; evaluate on a demo account. This portfolio makes no trading-return claims.
